Parameter         Type    Default   Description
─────────────────────────────────────────────────────────────────────────────
lowercase         bool    True      Convert to lowercase
remove_punct      bool    True      Remove punctuation
remove_stops      bool    True      Remove stopwords
remove_nums       bool    False     Remove numbers

stem              bool    False     Apply stemming
lemmatize         bool    False     Apply lemmatization (recommended)
custom_stopwords  set     None      Custom stopword set

EXAMPLE 1: Basic Preprocessing

from src.preprocessing import preprocess_text

EXAMPLE 2: DataFrame Processing
────────────────────────────────────────────────────────────────────────────

df = preprocess_dataframe(
    df,
    text_column="text",
    output_column="clean_tokens",
    lowercase=True,
    remove_stops=True,
    lemmatize=True,
    min_length=3
)

EXAMPLE 3: Custom Pipeline
────────────────────────────────────────────────────────────────────────────
from src.preprocessing import (
    simple_tokenize,
    to_lowercase,
    remove_stopwords,
    lemmatize_tokens
)

tokens = simple_tokenize(text)
tokens = to_lowercase(tokens)
tokens = remove_stopwords(tokens)
tokens = lemmatize_tokens(tokens)

================================================================================
                         PREPROCESSING PIPELINE
================================================================================

Text Input
    ↓
[Remove Punctuation] ← optional
    ↓
[Tokenize] ← splits into words
    ↓
[Lowercase] ← optional
    ↓
[Remove Stopwords] ← optional
    ↓
[Remove Numbers] ← optional
    ↓
[Remove Short Tokens] ← min_length filter
    ↓
[Lemmatize or Stem] ← optional, mutually exclusive
    ↓
Clean Tokens

================================================================================
                           COMMON USE CASES
================================================================================

For ML Classification:
    preprocess_text(text, lemmatize=True, min_length=3)

    preprocess_text(text, lemmatize=True, remove_nums=True, min_length=3)

For Word Embeddings:
    preprocess_text(text, remove_stops=False, lemmatize=True)

Minimal Preprocessing:
    preprocess_text(text, lowercase=True, remove_stops=False)
