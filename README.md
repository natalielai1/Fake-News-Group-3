# Fake News Detection Project
AITP project on fake news detection.

## Project Structure

```
Fake-News-Group-3/
├── data/                   # Data directory (gitignored)
│   ├── raw/               # Original, immutable datasets
│   ├── processed/         # Cleaned and preprocessed data
│   └── external/          # External datasets from third-party sources
│
├── src/                   # Source code for the project
│   ├── data/              # Data loading and management
│   │   └── load_data.py   # Dataset loading utilities
│   ├── preprocessing/     # Text preprocessing and cleaning
│   │   └── tokenizer.py       # Tokenization and preprocessing functions
│   ├── features/          # Feature engineering (to be implemented)
│   ├── models/            # Model definitions (to be implemented)
│   └── utils/             # General utility functions
│
├── notebooks/             # Jupyter notebooks for exploration and analysis
│
├── results/               # Generated outputs
│   ├── figures/           # Visualizations and plots
│   ├── models/            # Trained model artifacts (gitignored if large)
│   └── metrics/           # Performance metrics and evaluation results
│
├── tests/                 # Unit tests and integration tests
│
├── scripts/               # Executable scripts
│   └── preprocess_data.py # Data preprocessing pipeline
│
├── config/                # Configuration files
│   └── config.yaml        # Project configuration parameters
│
├── .gitignore            # Specifies intentionally untracked files
├── environment.yml       # Conda environment specification
├── requirements.txt      # Pip requirements
└── README.md            # This file
```

### Directory Descriptions

- **`data/`**: All datasets live here. Raw data stays unchanged; processed data is generated by scripts.
- **`src/`**: Reusable Python modules and functions. All team members should add their utility functions here.
- **`notebooks/`**: Jupyter notebooks for exploratory data analysis and experimentation. Name with numbers (e.g., `01_data_exploration.ipynb`).
- **`results/`**: All outputs from model training, evaluation, and visualization.
- **`scripts/`**: Entry point scripts that orchestrate workflows by importing from `src/`.
- **`config/`**: Configuration files for different experiments and parameters.
- **`tests/`**: Unit tests to ensure code quality (use pytest).

### Workflow Guidelines

1. **Exploring**: Use Jupyter notebooks in `notebooks/` for initial exploration and prototyping
2. **Developing**: When code works, move reusable functions to appropriate modules in `src/`
3. **Running**: Execute workflows using scripts in `scripts/` that import from `src/`
4. **Testing**: Add tests in `tests/` for critical functionality
5. **Configuring**: Modify `config/config.yaml` instead of hardcoding parameters

## Environment Setup

### Prerequisites
- [Anaconda](https://www.anaconda.com/download) or [Miniconda](https://docs.conda.io/en/latest/miniconda.html) installed
- Git

### Setup Instructions

#### Option 1: Using Conda (Recommended)

1. Clone the repository:
```bash
git clone https://github.com/natalielai1/Fake-News-Group-3.git
cd Fake-News-Group-3
```

2. Create the conda environment:
```bash
conda env create -f environment.yml
```

3. Activate the environment:
```bash
conda activate fake-news-detection
```

#### Option 2: Using pip only
```bash
pip install -r requirements.txt
```

### Updating the Environment
Throughout the project we will probably discover new dependencies we need. When new dependencies are added:
```bash
conda activate fake-news-detection
conda env update -f environment.yml --prune
```

### Deactivating the Environment
```bash
conda deactivate
```

### Removing the Environment
```bash
conda env remove -n fake-news-detection
```

## Getting started


### 1. Prepare Your Data
Place the raw Kaggle dataset (`WELFake_Dataset.csv`) in the `data/raw/` directory.

### 2. Run Preprocessing
```bash
python scripts/preprocess_data.py
```

This will:
- Load the raw dataset
- Tokenize the text
- Save the cleaned data to `data/processed/preprocessed_dataset.csv`

⚠️ Note that the current preprocessing module (defined in `src/preprocessing/tokenizer.py`) is only a demo. Based on our results we will have to tune our preprocessing later. This means that we will also likely save multiple versions of preprocessed dataset later; we should figure out a way to do this systematically.

### 3. Check results
Run all blocks in `notebooks/test_install.ipynb`. If everything worked you should see the same output.
